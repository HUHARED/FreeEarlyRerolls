# Free Early Rerolls | 前三波免费刷新

Compatible with Brotato 1.2 / Primal Dread.

## Features / 功能

* Waves 1–3: Unlimited free rerolls.
* Wave 4+: First reroll of each wave is free.
* Applies to both shop and level-up reward rerolls.
* Subsequent rerolls use the vanilla game's pricing formula.

### 中文说明

* 第 1～3 波：无限次免费刷新。
* 第 4 波开始：每波首次刷新免费。
* 同时影响商店与升级奖励界面。
* 后续刷新按照原版价格计算，不破坏原版价格加成机制。

Do not enable this mod alongside other mods that override the same reroll pricing function.

不建议与其他修改刷新价格的 Mod 同时启用，以免产生冲突。
